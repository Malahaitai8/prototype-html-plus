# Roadmap

## V1 - Usable prototype-html-plus Skill

Goal: build a usable Codex Skill for interactive HTML product prototypes without over-engineering.

- Step 0: Project bootstrap and V1 plan persistence.
- Step 1: Reference Skill research and decisions.
- Step 2: Requirement intake and structured questioning.
- Step 3: Wireframe mode.
- Step 4: Basic high-fidelity admin mode.
- Step 5: Side documentation and numbered pin annotations.
- Step 6: Region screenshot rebuild mode.
- Step 7: Local preview and verification workflow.
- Step 8: V1 cleanup, GitHub upload, and optional `v0.1.0` tag.

## V2 - Expanded prototype workflows

- Full-page screenshot rebuild.
- Multi-page prototypes and page navigation.
- More complete design-system support.
- Existing HTML/CSS import.
- Multi-version prototype generation.
- Export prototypes to single-file HTML, image, or PDF.
- Stronger screenshot comparison checks.
- GitHub Actions checks for HTML output.
- PC, mobile, and large-screen scenario support.
- Configurable requirement forms.
- User-defined visual baselines.

## V3 - Production polish

- More robust packaging and release workflow.
- Wider starter component library.
- Optional CLI or automation helpers if repeated manual work justifies them.
- Broader forward-testing against realistic product-design tasks.
