# Generated Wireframe Test Artifacts

This folder contains HTML files generated during real Skill test threads.

They are committed as reference outputs for reviewers who want to inspect the current behavior of `prototype-html-plus`, but they are not part of the installable Skill.

Rules for this folder:

- Do not load these files as built-in Skill templates.
- Do not copy their business content into unrelated user prototypes.
- Use them only as examples of generated output quality, interaction shape, documentation panels, and annotation behavior.
- Keep installable Skill files under `skills/prototype-html-plus/`.
