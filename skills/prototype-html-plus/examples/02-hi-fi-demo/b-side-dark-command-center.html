右侧说明文档

本 demo 来自已确认 UI 风格：暗色数据指挥中心。它不是基础后台换色，而是改变了信息节奏、空间组织、状态表达和监控材质。

原型说明

Step A 仍只做同步健康度、节点态势、告警流和异常处理队列，不扩展到规则配置或审计。

功能说明

运营人员可切换异常优先、筛选区域、锁定异常行，并确认当前异常状态。

字段说明

核心字段包括在线摄像头、延迟、异常数、区域、告警级别、心跳状态和刷新频率。

交互说明

支持标注显隐、全局/异常优先模式、区域刷新、队列选中和异常确认。

编号标注

指挥头部
显示风格路线、当前任务和高优先级命令。
生命体征
高密度指标用于快速判断同步健康度。
态势图
用发光节点表达区域分布和异常热区。
告警流
按紧急程度展示最近事件，避免只看静态卡片。
处理队列
承载异常优先筛选和行级锁定动作。

验收点

用户应能感知这是暗色指挥中心风格；布局、状态和材质应明显不同于白底基础后台。
