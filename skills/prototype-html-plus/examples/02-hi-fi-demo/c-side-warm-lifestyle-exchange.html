右侧说明文档

本 demo 来自已确认 UI 风格：温暖生活方式 / 社区友好 / 年轻可信。它保留微信小程序路径，但不只是基础 WeUI 单元格换色。

原型说明

Step A 只覆盖发布闲置、浏览物品、发起预约和查看风险边界。

功能说明

用户通过生活场景发现物品，查看故事感描述，使用低压力预约动作完成交换意向。

字段说明

核心字段包括物品名称、交换类型、认证状态、自提时间、风险边界和预约反馈。

交互说明

支持标注显隐、亲子筛选、故事 toast、温和预约、发布弹层和边界说明。

编号标注

品牌化头部
用更轻的品牌名称和发布入口建立生活方式感。
生活方式首屏
用视觉主张替代基础列表首屏，降低交易压力。
场景化分组
按生活场景组织信息，而不是只做分类 Tab。
故事卡片
物品卡强调来源、交换心态和可信标签。
风险边界
保持平台不担保、不鼓励大额交易的约束。

验收点

用户应感知温暖、可信、社区友好；布局和节奏应不同于基础 WeUI 列表。
